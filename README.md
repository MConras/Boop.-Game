# boop.

> A C-based digital adaptation of the strategic board game **boop.**, developed as a university project at UFCA.

## Prerequisites

To compile and run this project, you will need:

* **C Compiler:** [GCC](https://gcc.gnu.org/) or [Clang](https://clang.llvm.org/)
* **Git:** To clone the repository

## Getting Started

Follow these steps to get the game running on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/MConras/boop.-game.git
cd boop.-game
```

### 2. Compile the project
Compile all C source files into an executable named `boop.`:
```bash
gcc *.c -o boop
```

### 3. Run the game
Execute the compiled binary:
```bash
./boop
```
